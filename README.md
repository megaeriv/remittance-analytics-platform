# NovaPay Remittance Analytics Platform

An end-to-end analytics engineering portfolio project that transforms
synthetic remittance, customer, payment, exchange-rate and compliance
data into reliable business information.

## Project status

Planning and business-requirements definition.

## Business problem

NovaPay needs consistent reporting across customer activity, financial
performance, transaction processing, payment exceptions, identity
verification and compliance operations.

The solution distinguishes customer-abandoned transaction drafts from
submitted transactions that are awaiting payment confirmation from a
card acquirer.

## Planned solution

The project will demonstrate:

- synthetic data generation using Python;
- data ingestion and validation;
- SQL transformation and dimensional modelling;
- transaction and payment event histories;
- automated data-quality testing;
- Power BI semantic modelling and reporting;
- Microsoft Fabric lakehouse and pipeline implementation;
- Git and GitHub version control;
- technical and business documentation.

## Data notice

All data used in this project will be synthetic. The repository will
not contain confidential information or personally identifiable data
from any real customer, company or financial institution.
